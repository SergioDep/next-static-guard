# Security

Next Static Guard analyzes supported Next.js server/client boundaries locally. It reads source and package metadata, parses repository configuration as data, and reports names and locations. It does not execute application code, read `.env` values, send source to services, or provide a general authorization or vulnerability audit.

Use Node 24.21.0 or a later Node 24 release and Git 2.47.0 or later for comparisons. Supported Next.js and React versions, excluded features, and analysis limits are recorded in every report. Partial coverage requires review; `--strict-coverage` makes that state fail a CI check.

The published CLI contains only its runtime dependencies. Run `npm audit --omit=dev --workspaces=false` in this repository to check that dependency surface; CI fails on high or critical advisories there. The GuardLab fixture workspace (`tests/fixtures/guardlab/base`) pins Next.js 16.3.8, the framework version of the supported profile, and is outside that surface: it is test input, is not deployed, and is absent from the packed CLI. As of 2026-11-10, `npm audit` reports three advisories for Next.js 16.0.0 to 16.4.0 ([GHSA-2464-fhr4-w9xw](https://github.com/advisories/GHSA-2464-fhr4-w9xw), [GHSA-p3m5-59mp-jv5r](https://github.com/advisories/GHSA-p3m5-59mp-jv5r), [GHSA-673q-mjm6-r5xr](https://github.com/advisories/GHSA-673q-mjm6-r5xr)). Moving the supported profile to a patched Next.js release requires repeating the framework observations. The development comparison lab currently inherits the unpatched [braces stack exhaustion advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) through ESLint's Next plugin. It is absent from the packed CLI and the lab uses fixed, authored patterns. Reevaluate that development dependency when an upstream fix is published.

Report ordinary false positives, false negatives, and compatibility failures using the repository's issue templates, with a minimal example containing fictional data. For a security vulnerability, use GitHub private reporting when available or request a private contact channel from the maintainer before sharing sensitive details. Include the tool version, ruleset, platform, and a minimal reproduction.
