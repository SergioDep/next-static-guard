# NSG002: Client dependency in a Server Component

Profile: Next 16.3.8, React/React DOM 19.3.0, App Router, standard Turbopack. Ruleset 1.1.0 level: `warn`, uncertified. Severity: high. Confidence: high.

## Detection

An RSC use without a client boundary reaches `client-only` or retains an import or uses a resolved `useState`, `useEffect`, `useReducer`, or Next `useRouter` hook.

## Example and correction

A Server Component calls React's `useState`.

Extract the interactive part into a small module with a valid `use client` directive. Keep server data access in the parent and pass supported props.

## Valid controls

A transitive client dependency can call client hooks. React `use` and `useId`, and user-defined functions with hook-like names, do not trigger this rule.

## Evidence and limitations

Evidence identifies the real imported API or marker and the RSC use path. Name matching alone is insufficient.

The named import and hook-use restrictions apply to RSC uses. General Rules of Hooks checks and hooks in arbitrary handler/function bodies are outside this rule. Unknown reference identity produces a limitation.
