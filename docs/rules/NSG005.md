# NSG005: Declared confidential data sent or configured for publication

Profile: Next 16.3.8, React/React DOM 19.3.0, App Router, standard Turbopack. Ruleset 1.1.0 level: `warn`, uncertified. Severity: critical for secrets; high for private data. Confidence: high.

## Detection

An explicitly declared confidential origin reaches client props, a client-referenced Server Function return, a consumed client value export, or a recognized `next.config.env` key.

## Example and correction

A Server Component passes a declared secret environment value through an alias into a client prop.

Keep the value on the server and select a DTO containing only required nonconfidential fields. For a configuration sink, remove the confidential key from `next.config.env`. Review previous exposure without including the value in the report.

## Valid controls

Server-only use and DTOs that exclude declared fields are valid. Encrypted inline-action captures alone are not plaintext disclosure.

## Evidence and limitations

Evidence contains symbolic origin, declared field path, and publication sink. A configuration finding states public substitution policy; it does not claim an unused value was observed in a served bundle.

Sensitivity requires explicit key/export/field declarations. Unknown transformations, missing field facts, recursion, or data beyond the local budget produce limitations. General secret discovery and authorization are outside scope.
