# NSG004: Unsupported server-created prop value

Profile: Next 16.3.8, React/React DOM 19.3.0, App Router, standard Turbopack. Ruleset 1.1.0 level: `warn`, uncertified. Severity: high. Confidence: high.

## Detection

A resolved RSC-to-Client Component prop contains a known ordinary server-created function, custom class instance, null-prototype object, or nonregistered symbol.

## Example and correction

A Server Component passes an ordinary `onClick` function to a Client Component.

Create the event handler in the client, pass supported data, or use an actual async Server Function reference. For custom instances, construct a DTO from required supported fields.

## Valid controls

Supported primitives, Date, Map, Set, typed arrays, ArrayBuffer, `Symbol.for`, JSX, known Promise results, Server Functions, and exported client references are valid when their contents are supported.

## Evidence and limitations

The primary location is the offending prop value. Evidence includes the rejected value origin and the resolved client prop sink; nested fields are inspected.

Unknown spreads, Promise results, constructors, wrappers, and transformations produce `unknown-value`. JSON-only serialization rules are not used. Serialization of Server Function arguments and returns is outside NSG004's prop scope; NSG005 checks confidentiality of explicit returns.
